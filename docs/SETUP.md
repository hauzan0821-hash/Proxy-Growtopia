# Setup cepat

1. Install .NET 8 SDK.
2. Copy `Proxy/appsettings.example.json` jadi `Proxy/appsettings.json` (atau edit file yang sudah ada).
3. Isi `AppName`, `OwnerId`, `Version`, dan `Secret` bila app KeyAuth kamu butuh secret.
4. Buka `proxy1.sln` lalu jalankan dari Visual Studio.
5. Atau jalankan `Proxy/start-proxy.bat`.
